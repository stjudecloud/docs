# PeCan Press Release Design

**Date:** March 5, 2026  
**Project:** St. Jude Cloud PeCan Product Enhancement Press Release  
**Approach:** Impact-Driven Narrative

## Overview

This press release announces major enhancements to St. Jude Cloud's PeCan (Pediatric Cancer Knowledgebase) platform, introducing dynamic cohort building and comparative analysis capabilities across 11,500 pediatric cancer samples and five integrated data facets.

**Target Audience:** Researchers, scientists, scientific publications, academic institutions  
**Tone:** Professional but accessible, impact-focused and inspirational

## Key Message

The core message is transformation: research workflows that previously required months of data preparation and custom analysis pipelines can now be accomplished in real-time within a browser session. This fundamentally changes how pediatric cancer researchers generate and test hypotheses.

## Structure & Design

### 1. Headline & Opening

**Headline Strategy:** Action-oriented, emphasizing speed transformation
- Example: "St. Jude Cloud Transforms Pediatric Cancer Research from Months to Minutes with New PeCan Capabilities"

**Dateline:** MEMPHIS, TN — [Date TBD], 2026

**Opening Paragraph (Lede):**
- Lead with the transformation narrative: what researchers can now do that they couldn't before
- Emphasize shift from "months of data preparation" to "real-time hypothesis generation"
- Establish scale immediately: 11,500 samples, 5 data facets (variants, gene expression, epigenetics, mutational signatures, histology)
- Highlight that this is entirely browser-based, no downloads or infrastructure required

**Second Paragraph:**
- Provide concrete example using the t-SNE clustering scenario
- Show the workflow: identify unexpected cluster → create cohort → stratify by mutational signatures → pivot to histology
- Demonstrate how each question leads naturally to the next with data already at hand

### 2. Quote & Context

**First Quote:**
- Place after establishing transformation to reinforce the message
- Use compelling quote: "This unlocks a completely different way of doing science. You see something interesting, build a cohort around it, stratify across other data modalities, and chase the thread immediately. That kind of rapid, iterative hypothesis generation just wasn't possible when every question meant weeks of data preparation and analysis."
- Attribution: [Name], [Title] — TBD

**Context Paragraph:**
- Position PeCan as providing the world's largest integrated pediatric cancer dataset
- Emphasize 11,500 samples across [X] diagnoses — TBD
- Highlight curation for childhood cancers' unique biology
- Differentiate from adult-focused resources (TCGA, etc.)
- Mention rare tumor types underrepresented elsewhere
- Note expertly curated cohorts from St. Jude scientists who pioneered disease classifications

### 3. Key Features & Capabilities

**Presentation Strategy:** Narrative flow showing how researchers use features, not bullet lists

**Dynamic Cohort Building:**
- Intuitive creation process: naming, describing, saving new or adding to existing cohorts
- Transparency: Sample IDs, diagnosis categories, metadata visible before finalizing
- Ensures researchers know exactly what's in their cohorts

**Cross-Facet Exploration:**
- Seamless exploration across all five data facets
- Both user-created and expertly curated cohorts available
- Samples can be explored across all facets simultaneously

**Comparison Mode:**
- Side-by-side visualization of two cohorts
- Easy cohort selection and flexible positioning
- Each data facet optimized with appropriate layouts for comparison
- Data availability information across all facets
- Enables exploration of what distinguishes one group from another

**Central Dashboard:**
- Workspace for managing cohorts
- Dedicated location for tracking explorations
- Improved navigation throughout the application

**Length:** 2-3 paragraphs total, maintain momentum while covering all features

## Design Rationale

**Why Impact-Driven Narrative:**
- Audience (researchers, scientific publications) cares about scientific impact before features
- Opens with transformation story that immediately conveys value
- Professional-but-accessible tone combined with inspirational messaging
- Makes the announcement memorable while delivering technical substance
- Positions PeCan as transformative rather than incremental

**Why This Structure:**
- Leads with the "so what" rather than the "what"
- Uses concrete example early to make abstract benefits tangible
- Quote reinforces message from credible voice
- Features woven into narrative showing actual research workflows
- Maintains momentum throughout without becoming a feature list

## Success Criteria

A successful press release will:
- Clearly communicate the transformation in research workflow speed
- Make the technical capabilities accessible to broad scientific audience
- Differentiate PeCan from other genomics platforms
- Generate interest from pediatric cancer researchers
- Provide sufficient detail for scientific publications
- Include compelling quote that media can excerpt
- Maintain St. Jude's reputation for scientific excellence and open science mission
