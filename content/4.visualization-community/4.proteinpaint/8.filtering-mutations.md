## Filtering mutations based on class and origin

ProteinPaint uses the color of the discs to represent the mutation classes, as indicated in the legend:

![image 4](/img/visualization-community/proteinpaint/filtering-mutations/image4.png)

The numbers in the legend indicate the total number of mutations currently shown for each class.
Clicking on a class shows a menu:

![image 2](/img/visualization-community/proteinpaint/filtering-mutations/image2.png)

Use the options in the menu to show/hide mutations from a selected class.
The following screenshot shows the view after hiding all missense mutations, making nonsense mutations (orange) the most abundant class.
There is also a strikethrough to the MISSENSE class label in legend, indicating it is hidden

![image 10](/img/visualization-community/proteinpaint/filtering-mutations/image10.png)

![image 6](/img/visualization-community/proteinpaint/filtering-mutations/image6.png)

As another example, the following shows only splice site mutations, with strikethroughs in all the other class labels in the legend:

![image 9](/img/visualization-community/proteinpaint/filtering-mutations/image9.png)

![image 3](/img/visualization-community/proteinpaint/filtering-mutations/image3.png)

To restore mutations for of all classes, click on any mutation class button then select "Show all classes":

![image 5](/img/visualization-community/proteinpaint/filtering-mutations/image5.png)

In the Pediatric data set, germline and relapse mutations are also denoted in the "Origin" section of the legend:

![image 7](/img/visualization-community/proteinpaint/filtering-mutations/image7.png)

Click on an origin type to see a menu similar to the mutation class menu:

![image 1](/img/visualization-community/proteinpaint/filtering-mutations/image1.png)

Using these options, only germline mutations are shown as below:

![image 8](/img/visualization-community/proteinpaint/filtering-mutations/image8.png)
