**Overview**
Analysis of samples from St. Jude Children's Research Hospital, specifically from PCGP, Clinical Pilot, and G4K were shown originally in [Figure 5 of McLeod et al](https://cancerdiscovery.aacrjournals.org/content/11/5/1082.long).
Now, Real-time Clinical Genomics samples have been incorporated into the visualization.
These samples are depicted via a heatmap where COSMIC single base substitution (SBS) mutational signatures in pediatric cancer subtypes were analyzed by WGS.

## Heatmap View

Identification of COSMIC SBS signatures (v3.3) upon consideration of somatic variants was performed using SigProfilerExtractor (v1.1.20) on pediatric tumor samples grouped by subtype across over 1,800 samples (**Figure 1**).
Users can explore a sample summary bar plot view by clicking the subtype (y-axis), SBS signature (x-axis), the subtype with a particular SBS signature (cell), or the Summary tab.
Use the Subtype Root, Subtype, and Signatures filters to narrow the heatmap to specific subtypes or COSMIC SBS signatures.

![heatmap](/img/pecan/data-facets/mutational-signatures/Heatmap.png)

**Figure 1:**
Heatmap View.
The heatmap is comprised of sample data and COSMIC SBS mutational signatures that have a cosine similarity greater than 0.8.

## Summary

Users can view a summary bar plot consisting of the mutational signatures within a given subtype in 4 separate ways: 1) samples by subtype (**Figure 2**), 2) samples by the COSMIC mutational signature (**Figure 3**), 3) samples for a specific subtype with a specific mutational signature (**Figure 4**), or 4) all samples via the Summary tab.

Selecting a subtype takes you to a dedicated summary tab of all samples in that group (**Figure 2**).
The tab includes a summary of the signatures observed in the samples, the proportion of SNVs per signature in each sample, the mutational burden, and the cosine similarity score, along with a metadata panel.
Selecting a sample from the summary opens that sample in a new tab (see [Sample View](#sample-view)).

![subtype barplot](/img/pecan/data-facets/mutational-signatures/subtype_barplot.png)

**Figure 2:**
Subtype Selection from Heatmap View.
This view allows a user to investigate COSMIC mutational signature summaries and mutational burden per sample of a given subtype.

![sbs barplot](/img/pecan/data-facets/mutational-signatures/SBS_barplot.png)

**Figure 3:**
COSMIC SBS Selection from Heatmap View.
This view allows a user to investigate mutational signature summaries and mutational burden per sample cohort of a given SBS.

![subtype sbs barplot](/img/pecan/data-facets/mutational-signatures/subtype_sbs_barplot.png)

**Figure 4:**
Subtype with a specific COSMIC SBS selection from Heatmap View.
This view allows a user to investigate mutational signature summaries and mutational burden per sample cohort of a given subtype with a specific COSMIC mutational signature.

Each bar plot provides a title, the total number of samples, the method used to identify the mutational signatures, the summary of mutational signatures, the summary of mutational signatures per sample, the mutational burden per sample, and the cosine similarity score per sample.
Additionally, clicking the mutational signature legend will provide summary data (e.g., total number of SNVs and % within that sample) and a link to the COSMIC website.
Selecting an individual sample ID opens that sample in a new tab with a summary of the sample name and total number of SNVs found within that individual sample.

## Table View

A table view (**Figure 5**) is also available for each summary view so that users can see the same information as the bar plot view in a tabular manner.
The table view includes Sample ID, subtype, sample type, the total number of somatic SNVs, the existing mutational signature per sample, and the cosine similarity.

![table view](/img/pecan/data-facets/mutational-signatures/table_view.png)

**Figure 5.**
Table View:
The table view is an alternative to the bar plot view for each use case described in **Figures 2-4**.

Users can select a mutational signature (column 4) and see a summary of the number and proportion of SNVs and/or a link to the COSMIC website.

## Sample View

Selecting an individual sample will navigate users to a sample page view (**Figure 6 & 7**), which provides the number of mutations per codon for each base-pair change.
The sample metadata – diagnosis, sample type, data type, total somatic SNVs, methods, cosine similarity, and reference genome – is available in a collapsible table to the right of the screen.
The colors per base change are related to the COSMIC website.
Additionally, each SBS mutational signature COSMIC depiction is given as a reference with a link to the website.
